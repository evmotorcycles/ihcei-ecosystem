# The Rational Thinking (RT) container

RT is the default operating frame of modern science, engineering and law. It studies
**what is measured**, builds models that **predict measurements**, and settles disputes by
**comparing predictions to observations**.

This skill exists to state the RT reading of any field **fairly and at full strength**,
because a reframe that beats a strawman has proved nothing.

## What RT actually is

| | RT |
|---|---|
| **Object of study** | measured quantities and the relations between them |
| **Warrant** | predictive accuracy, reproducibility, independent replication |
| **Settles disputes by** | experiment, error bars, pre-registration, adversarial review |
| **Ontology** | agnostic by design — it does not need to say what a thing "really is" |
| **Failure mode** | mistaking a *successful model* for a *complete description* |

**RT is not "surface-level" and it is not naive.** It is a discipline for not fooling
yourself. Its central achievement is the error bar.

## Stating an RT reading fairly — the three obligations

1. **Give the strongest version.** Use the mainstream account as its own practitioners
   would state it, not a caricature ("shut up and calculate" is a slogan, not a theory).
2. **Name what it predicts, quantitatively.** An RT reading earns its place by numbers.
3. **Name its open problems honestly** — RT fields keep their own lists of these, and
   using them is fair; inventing extra ones is not.

## What RT genuinely does not settle

RT is agnostic on *interpretation*. Several distinct ontologies can be
**empirically equivalent** — identical predictions, different stories about what exists.
Where that is true, RT does not adjudicate, and saying so is not a weakness of RT; it is
RT being precise about its own scope.

**But empirical equivalence is a claim that must be checked, not assumed.** A reframe that
changes predictions is not an interpretation — it is a rival theory, and it inherits the
full burden of evidence.

## The RT-side firewall (mandatory)

Before accepting any reframe of an RT field, run these checks:

1. **Does the reframe change any prediction?** If yes → it is a rival theory. Demand the
   discriminating experiment. If no → it is an interpretation, and it cannot claim
   empirical support from the field's existing successes.
2. **Does it contradict an established no-go theorem?** No-go results (no-signalling,
   no-cloning, Bell, CAP, Arrow, Gödel) are proofs about what *cannot* happen under stated
   assumptions. A reframe that violates one has either changed an assumption — which must
   be named — or is simply wrong.
3. **Does it borrow the RT field's predictive credit?** A reframe that redescribes results
   it did not predict has earned *coherence*, not *confirmation*.
4. **Is a metaphor doing load-bearing work?** "It's like a video game / a folder icon / a
   headset" is a teaching aid. The moment a conclusion depends on the metaphor rather than
   on a derivation, the conclusion is about the metaphor.

## When to defend RT against a reframe

Say plainly, without hedging, when a proposed reframe:

- contradicts a measured result (not an interpretation — a *measurement*);
- requires a quantity to take a value the field has bounded experimentally;
- treats an unresolved interpretive question as though it were settled in its favour;
- explains a phenomenon *after the fact* and calls that a prediction.

Being able to say "this part is simply wrong" is what makes the rest of the reframe worth
taking seriously. A framework that cannot be told it is wrong about physics will not be
believed when it is right about governance.
