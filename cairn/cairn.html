Page Code

The permission table. Cairn may only touch what this table allows — and it is default-deny, so anything not listed is refused.

Why a table and not a judgement. A rule you can read is a rule that cannot be talked around. Cairn cannot be persuaded to widen its own permissions — only you can, here.
