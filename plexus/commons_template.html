How a thing is described, and what is actually holding it up

Every shape below is stored twice. Once the way people usually describe it, and once with the dependencies that are really there. The number in orange is the distance between those two: how much worse than you thought.

A shape is parts and links. Nothing else — there is no field for a name, an address or an amount, because a shape with a free-text box in it would end up holding one. That is why these can be shared and your own work cannot leak with them. Nothing leaves this device.

Eight shapes, written by one person in one sitting. That is a worked example, not yet a commons. It becomes a commons when a shape arrives from somebody who never read this page.

Does one of these describe yours?

List the parts of your own situation, one per line — whatever you would name if you were explaining it to someone. This only compares words, so treat what comes back as a place to start looking, never as a measurement.

No shape here uses those words. That does not mean none of them fits.
The library

What none of this shows. Nothing on this page is evidence that a shared library of shapes is worth anything commercially. That would be a contribution rate — the share of people who, having used this, give a shape back — and it is not measurable yet. The gate set in advance is 5% within 60 days of shipping. Below that, the idea was imaginary and this page is a nice diagram.
