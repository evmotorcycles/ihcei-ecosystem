The mechanism

Each member's draw is capped at a multiple of its own contribution. A larger pool has proportionally more claimants, so per-member capacity never improves. Pooling helps once — by giving each node a buffer it lacked. It does not help more.

Consequence for the architecture: the smallest useful cluster is the best one. k=2 — bilateral mutual guarantee — captures essentially the entire benefit at one twentieth the blast radius of the proposed k=20. If local pooling is adopted, adopt it small.
