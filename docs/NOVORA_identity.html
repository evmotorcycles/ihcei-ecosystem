NOVORA

Two hops · one gate · nothing hidden

The mark is the product. Every result in this programme has the same shape — a signal must be encoded and then decoded, and the gap between them is where things fail. So the identity is built from that geometry, not decorated with it.

The primitive every mark is built from

One 48-unit grid. One stroke weight. Two arcs and a node. Each product's mark is a transformation of the same primitive — because each product is a different operation on the same channel.

The two arcs never touch. That is deliberate and it is the whole thesis: the hops multiply, so either one at zero collapses the result. The node at the centre is what survives the channel — and it is the only solid element in the entire system.

Why the mark is the flagship

A logo is a promise you can be held to. This one encodes a claim that can be checked. The two arcs don't touch because the hops multiply. The gate stops short because it has three verdicts, not two. The mesh has no centre because agency hoarding is the failure mode it exists to prevent. Every geometric decision restates a finding that has a spec hash behind it.

And one honest constraint

Marks that encode claims have to change when the claims do. The LISM chord now carries a stated domain limit — the product form is wrong where records are redundantly copied, by a factor of 195 in quantum decoherence. The mark still reads linear not quadratic, which is what was measured, and the boundary lives in the documentation rather than being smuggled into the geometry.
